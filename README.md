# نظام إدارة المنتجات والمبيعات عبر الطرفية (CLI)
### المشروع البرمجي المستقل - المرحلة الثانية (AT-02-A04)

مشروع برمجي متكامل ومبني باستخدام **TypeScript** و **Node.js** لإدارة المخزون والمبيعات، مع تطبيق صارم لمبادئ البرمجة الحديثة (Strict Mode، الوراثة النقية، معالجة الاستثناءات المخصصة، واختبارات الوحدة الآلية).

---

## 🚀 المميزات الرئيسية
1. **إدارة المنتجات:** إضافة أصناف جديدة مع التحقق الصارم من صحة المدخلات (منع الأسعار السالبة، منع تكرار المعرف، ومنع الأسماء الفارغة).
2. **البحث السريع:** إمكانية البحث بالاسم أو التصنيف مع تجاهل حالة الأحرف.
3. **الميزة الجديدة المباشرة (نظام البيع والفواتير):**
   * خصم الكميات المباعة من المخزون تلقائياً.
   * تحويل حالة المنتج إلى `Out of Stock` آلياً عند وصول الكمية للصفر.
   * منع البيع في حال عدم كفاية المخزون عبر استثناء `InsufficientStockError`.
   * إصدار فاتورة بيع لكل عملية تحتوي على (المعرف، الكمية، الإجمالي، التاريخ).
4. **التقارير الإحصائية:**
   * **تقرير المخزون:** حساب عدد الأصناف المتوفرة والمنتهية وإجمالي القيمة المالية.
   * **تقرير المبيعات:** رصد إجمالي القطع المباعة والأرباح/الإيرادات الإجمالية.

## 📁 هيكلية المشروع (Modular Structure)

```text
ts-fundamentals/
├── src/
│   ├── types.ts           # واجهات البيانات (Product, SaleTransaction, Reports)
│   ├── errors.ts          # استثناءات مخصصة (ProductNotFoundError, InsufficientStockError, ...)
│   ├── store.ts           # منطق العمليات (إضافة، بحث، بيع، تقارير)
│   ├── sampleData.ts      # بيانات المخزون المبدئية
│   └── index.ts           # تشغيل العرض المباشر (CLI Live Demo)
├── tests/
│   └── store.test.ts      # 11 اختبار وحدة شامل (100% Pass)
├── tsconfig.json          # إعدادات TypeScript الصارمة
└── package.json           # إدارة التبعيات وأوامر التشغيل
```

## 🛠️ التثبيت والتشغيل

### 1. تثبيت الحزم:

```bash
npm start
```

### 3. تشغيل الاختبارات الآلية:
```bash

```
